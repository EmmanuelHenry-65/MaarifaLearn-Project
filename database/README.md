# Maarifa Learn Database

This folder contains the complete PostgreSQL database schema for the Maarifa Learn platform.

## Structure

- `schema/` - Database schema files
- `seeds/` - Sample data for development
- `migrations/` - Future database updates
- `backups/` - Database backups

## Database

- PostgreSQL
- Supabase
- Row Level Security (RLS)
- pgvector
- pgcrypto
